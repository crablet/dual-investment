# 实盘交易安全

修改交易代码时保留以下规则。日常操作见 [README 工作流程](../README.md#工作流程)。

## 账户与自动处理范围

- 使用专用账户，仅跟踪 BTC/USDT 卖方净仓。新期权订单须手动确认；后台可为已登记义务发送真实现货订单。
- 首次登记时，持仓和合约查询必须已完成，且合约尚未到期。到期前确认清仓或转为买方后停止跟踪。已登记、未完成的交割可在离线跨期后继续；到期后首次发现的仓位、历史成交和行权记录不能用于新增交割任务。
- 不识别用户在其他终端手工补交割。禁止手动干预同一义务，避免重复执行。
- 两种连接入口均在锁内先核对账户 UID，再更新凭据和连接。UID 缺失、无效或与 SQLite 绑定不一致时拒绝连接；删除凭据不解除绑定。清库会丢失跟踪与恢复记录，不能处理未完成义务。

## 同步与串行

- 连接和手动同步只查询数据、登记任务，交易由下单命令或后台维护执行。凭据、权限或账户状态错误时暂停自动重连。
- 净仓查询失败保留最后成功的数量与时间，不视为空仓；已登记仓位到期后仍可生成待确认任务。
- 账户缓存只用于展示。刷新在交易锁和维护锁外串行查询，已有刷新时跳过；连接变化后丢弃旧响应。
- 取锁顺序为**维护锁 → 交易锁**；后台遇忙跳过，恢复记录须在锁内重读和更新。

## 下单与交割

- `preview_strategy` 只做本地 Decimal 预估，不查询账户或发送请求。复核固定合约、数量和预估；真正提交时重查条款、过滤器与买一盘口，IOC 只用买一，深度不足则停止。
- 成交须有有效均价；现货可用累计成交额除以成交量推算。不得以委托限价代替成交事实；提交后回报解析失败按待确认处理。
- 卖 Put 至少覆盖名义本金，卖 Call 按合约保证金参数备资，同时满足可用余额与权益缓冲。备资和归集目标 **90%**，最终下单校验容差 **5 个百分点**、硬上限 **95%**；容差不得减少备资或扩大归集。见 [margin.rs](../src-tauri/src/strategy/margin.rs)。
- 订单历史、净仓和交割任务分开保存；同合约只有一个到期任务，历史卖出成交量不能累计为交割量。净仓更新与首次交割任务原子提交，重复扫描不重置任务；按同标的、同到期时刻组成批次。
- 核对行权记录的账户、合约、卖方方向、Put/Call 和到期时间，按记录 ID 去重。记录不完整则等待，互相矛盾则停止。最终数量以账户行权记录为准，不能用缓存仓量补足。
- 公开结算价可确认无需行权，但不能证明账户数量或现金流；缺少账户记录时这些字段保留为空。价内而行权数量未知时不得下单。
- 现货数量为 `确认行权张数 × unit`：卖 Put 买 BTC，卖 Call 卖 BTC。足额成交后完成任务，不再产生新现货订单。实现见 [settlement.rs](../src-tauri/src/app_state/settlement.rs)。

## 资金与恢复

- 每次动作前重查余额，只补已确认缺口，不预支未到账资金。开仓依次使用现货、活期；接货 USDT 依次使用现货、期权可划余款、活期。不足则等待后台复查。备资只查询有缺口资产的活期持仓，定期理财不参与备资。
- 按批次未交割数量预留：Put 为 `结算价 × 剩余 BTC × 1.02` USDT，Call 为剩余 BTC。已发出现货请求的余量只用于资金占用，不允许据此补发。见 [funding.rs](../src-tauri/src/app_state/funding.rs)。
- 未完成义务与批次持续保留资金、阻止新策略和无关资金动作。整批交割完成至少 **5 分钟**后才归集；收尾期间仍保留资金及其他仓位保证金。未开始的归集等待其他到期义务结束，已登记资金计划优先完成，批次间不得挪用预留。
- 发送前保存固定资金计划及对应的恢复记录；现货客户端订单号、任务与恢复记录须在同一事务中保存。资金请求须匹配到唯一的交易所历史记录，确认到账后才继续。
- 结果未知或历史匹配不唯一时，阻止新交易和资金动作，只查询原请求，禁止重发。现货终态成交不足或异常须人工核对；仅已阻断的资金记录允许人工核实后标记结果，解除阻断不重发。
- 重试由 [errors.rs](../src-tauri/src/errors.rs) 的结构化分类决定。查询退避不能用于重发订单或资金请求；POST 仅收到明确的时间戳拒绝码 `-1021` 时校时重试一次。
- 日志写入失败不改变已确认结果；交易、净仓和恢复所需的数据库写入失败仍阻止后续业务。
- “结束理财收尾”须满足已阻断、交易和划转已完成、无未确认请求，由用户确认；只关闭批次并解除预留，不发送请求。完整条件见 [settlement_recovery.rs](../src-tauri/src/app_state/settlement_recovery.rs)。
