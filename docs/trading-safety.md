# 实盘交易安全

## 授权与串行

- 连接和“同步订单”不发送交易或资金请求；“结算扫描”和后台维护可推进已确认订单的交易与资金动作。连接验证期权及现货权限，凭据、权限或账户状态错误时暂停自动重连。
- 每份本地数据库绑定一个 Binance 账户 UID。两种连接入口均在维护锁、交易锁内核对归属，通过后才更新凭据和当前连接；不同账户被拒绝，同账户更换 API Key 可继续使用原记录。UID 来自现有现货账户查询，缺失或无效时连接失败；删除凭据不解除数据库绑定。
- 页面读取本地快照；账户展示由后台或手动同步刷新，失败时保留上次成功的数据和更新时间并显示错误。展示缓存不参与下单、备资或恢复判断。
- 账户展示刷新单独串行，查询过程不持有交易或维护锁；后台已有展示刷新时跳过，不排队堆积。断开或更换连接后，旧连接返回的结果不会写入当前缓存。
- 下单或接管的手动确认覆盖后续恢复、结算和收尾，重连不重复授权。接管本身只登记真实义务仓。
- 维护共用维护锁，交易与恢复共用交易锁；取锁顺序为维护锁 → 交易锁。恢复记录在锁内重读和更新，后台繁忙时跳过。

## 界面语言与消息

- 语言偏好只影响展示，切换语言不会重新挂载业务页面或触发连接、下单、资金与恢复操作。词典加载失败时保留当前语言，启动阶段词典加载失败时回退英语；语言加载失败不进入业务自动重连流程。
- 订单、恢复、进度和错误消息通过 [Message](../src-tauri/src/messages.rs) 保存稳定代码与安全参数，在前端展示时翻译。参数中的金融数值保持 Decimal 字符串；日志与翻译结果均不能作为成交或资金事实。
- 重试和恢复继续依据后端结构化错误及记录状态。前端只接受经过校验的 `canAutoReconnect` 资格，翻译文案不能赋予重试许可；Tauri 传输错误或消息格式异常不授予自动重连资格。实现见 [errors.rs](../src-tauri/src/errors.rs) 与 [api.ts](../src/services/api.ts)。

## 下单与结算

- `preview_strategy` 只按方向、执行价、候选限价和输入数量进行本地 Decimal 计算，不读取账户或发送交易所请求。输入变化后旧预览失效；复核弹窗固定候选、数量和对应预估，预览成功不代表已通过实时交易检查。
- 后端核对用户确认的合约条款与数量，重查价格/数量过滤器和买一盘口。IOC 仅使用买一，量不足则停止。
- 已成交回报必须有有效成交均价；现货可由累计成交额和成交数量推算。不能用委托限价替代成交事实，提交后的回报解析失败按待确认结果处理。
- 卖 Put 至少覆盖名义本金，卖 Call 按 Binance 合约保证金参数备资，同时满足可用余额和权益缓冲。
- 备资与归集目标为 90%；最终下单校验另有 5 个百分点容差，硬上限 95%。容差不得减少备资或扩大归集。参数见 [margin.rs](../src-tauri/src/strategy/margin.rs)。
- 同标的、同到期时刻按批次结算，结算价取对应合约的 Binance 行权记录。结果齐全后整批备资，现货逐单确认足额成交；零成交终态订单不作为活跃持仓。

## 资金与恢复

- 只补真实缺口：开仓先用现货，再赎回活期；接货 USDT 依次用现货、期权可划余款、活期。每笔发送前重查余额，不预支未到账金额；接货不足则等待后台复查。
- 备资只查询有缺口资产的活期持仓；账户概览另行读取活期、定期和估值信息，定期理财查询不参与备资流程。
- 按整批剩余订单预留接货资金：Put 为 `结算价 × 已成交数量 × 1.02` USDT，Call 为已成交数量对应的 BTC。计算见 [funding.rs](../src-tauri/src/app_state/funding.rs)。
- 未完成批次保留资金并阻止新策略和无关资金动作。整批完成至少 5 分钟后才归集，保留其他仓位保证金；尚未开始的归集等其他到期义务完成，已登记的资金计划优先完成，批次间不得挪用预留。
- 发送前保存唯一恢复关联和固定资金计划；现货客户端订单号、策略订单与恢复记录原子落库。资金经交易所历史唯一确认并实际到账后才继续。
- 请求未确认或历史匹配不唯一时，阻止新交易和资金动作，只查询原请求，不重发。现货终态成交不足或异常须人工核对；仅已阻断的资金记录可在人工核实后标记结果，解除阻断不重发。
- 重试与恢复依据结构化错误类型、HTTP 状态和交易所错误码，规则集中在 [errors.rs](../src-tauri/src/errors.rs)。查询的短退避规则不能用于重发订单或资金请求；POST 仅在明确收到时间戳拒绝码 `-1021` 时校时后重试一次。
- 日志写入失败只在日志面板反馈，不改变已确认的交易或资金结果；恢复记录和订单的必要数据库写入失败仍会阻止后续业务。
- “结束理财收尾”仅限已阻断且交易、划转均已完成、无未确认请求的批次，由用户确认。只关闭批次并解除预留，不改变成交或资金结果、不发送请求；完整条件见 [settlement_recovery.rs](../src-tauri/src/app_state/settlement_recovery.rs)。
