## 这次数据说明什么

2026-11-16 的一次 Binance 报价采样中，得到 **66 组有效的 BTC 低买 / 卖 Put 配对**，覆盖 **8 个到期日、1–74 天期限**。直接卖 Put 的毛权利金在这 66 组中均高于配对双币赢产品的本期收益，**相对毛收益增幅中位数为 33.44%，毛年化差中位数为 12.41 个百分点**。毛年化差的四分位区间为 **6.46–24.61 个百分点**，完整范围为 **2.48–84.12 个百分点**。

README 首先展示全部样本的分布、各到期日中位数和范围。最高值 **84.12 个百分点**保留为可展开的演算案例，最低、中位附近及逐笔数据也全部公开。这些数字描述本次报价，不构成交易胜率或长期收益分布。

**宣传图采用毛收益口径：不扣开仓费，不计入备资缓冲。** 名义本金用于统一比较合约规模，不等于实际所需全部资金；图中收益不是扣除交易成本后的净收益。实际执行的费用与备资计算保留在[补充说明](#实际费用与备资)中。

这是报价测算，没有成交、申购或回测业绩。不能据此承诺未来每期都有优势，也不能推广到所有交易所、币种或产品。Binance 对双币赢披露的是零交易手续费；报价差本身无法证明其中有多少属于平台佣金、利润或其他定价因素。[官方双币赢说明](https://www.binance.com/en/support/faq/detail/09911be9f5754c34806bd3ab4a427e0e)

## 数据从哪里来

- **采样窗口：2026-11-16 10:52:31.882–10:52:40.420 UTC**，即北京时间 18:52:31–18:52:40。请求依次返回，不是同一毫秒的原子快照。
- 双币赢：`GET /sapi/v1/dci/product/list`，参数为 `optionType=PUT`、`exercisedCoin=BTC`、`investCoin=USDT`，每页 100 条，共 6 页、582 条产品报价。接口需要认证，只保存产品条款，不保存账号标识或认证信息。[官方接口文档](https://developers.binance.com/en/docs/catalog/investment-and-services-dual-investment/api/rest-api/market-data)
- 期权：从 `GET /eapi/v1/exchangeInfo` 读取合约条款，逐个调用 `GET /eapi/v1/depth?symbol=…&limit=10` 读取配对合约的**买一价和买一数量**。卖方可主动成交的参考是买盘，未使用卖一价、标记价或最近成交价来放大权利金。[官方市场数据文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-options/api/rest-api/market-data)
- 估算开仓费用的 BTC 指数价为 **64,503.71434783 USDT**，来自 `GET /eapi/v1/index?underlying=BTCUSDT`；现货参考价 **64,506.35 USDT** 来自 `GET /api/v3/ticker/price?symbol=BTCUSDT`。

采样仅发送读取产品及市场行情的 GET 请求，未启动交易客户端，未查询余额、持仓或成交历史，未下单、申购、赎回或划转。本文说明采样时间、来源、筛选规则与计算方法，逐笔比较结果见[对照表](yield-comparison-samples.md)。接口返回当前报价，日后重新调用不会重现同一时点的数据。

产品是否可购买以采样时接口返回为准，其他账户、地区或时刻的可用性可能不同。买一数量只是采样时的盘口，不保证提交订单时仍可成交；实际客户端仍会重新检查价格、数量、资金与权限。

## 怎样选样

全量样本按以下条件纳入，不按收益差大小剔除。README 总览保留全部有效配对，每个到期日单独展示，不只挑选优势最大的合约：

1. 只比较 USDT 低买 BTC 与对应的 BTCUSDT 卖 Put；目标价/执行价和 UTC 到期时间必须完全一致。
2. 只纳入应用候选范围内的 **1–90 天**产品，执行价低于采样现货价，双币赢显示可购买、期权状态为 `TRADING`。
3. 每个期权样本固定 **0.10 张**，本次每张对应 **1 BTC**。名义本金满足双币赢产品金额限制、数量满足合约限制，买一数量至少为 0.10 张。
4. 582 条产品中，412 条处于 1–90 天范围；其中找到 67 组目标价与到期时间一致的期权盘口。`BTC-270129-56000-P` 买一仅有 0.05 张，剔除后为 **66 组**。

总览图的两个面板分别展示毛年化差和毛收益相对增幅，**每个面板都包含全部 66 组**，每点一组。线段连接该期限的最小值与最大值，金色菱形和右侧数值为组内中位数；点的纵向错位仅用于区分相近报价。

## 最高样本怎样算

将 66 组有效配对按**同名义本金下的毛年化差**从高到低排序，最高为 `BTC-261117-64250-P`。该案例只用于演算极值，README 主展示采用上面的全量分布与中位数。

### 共同条款与观察值

| 输入 | 数值 |
| --- | --- |
| 低买目标价 / Put 执行价 `K` | 64,250 USDT |
| 到期 | 2026-11-17 08:00 UTC，北京时间 16:00 |
| 期限 `d` | 1 天；双币赢 `duration` 为 1，期权剩余时间向上取整也为 1 |
| 期权数量 `q` / 每张 BTC 数量 `u` | 0.10 张 / 1 BTC |
| 期权名义本金 `N = K × q × u` | 6,425 USDT |
| 双币赢报价 APR `a` | 223.55%，小数形式 2.2355 |
| 期权买一价 `P` / 买一数量 | 540 USDT / 43.12 张 |
| 双币赢观察时间 | 2026-11-16 10:52:32.468 UTC |
| 期权盘口获取时间 | 2026-11-16 10:52:38.787 UTC |
| 期权盘口交易所时间 `T` | 2026-11-16 10:52:37.601 UTC |

### 使用同一名义本金

双币赢申购金额为 6,425 USDT；期权以执行价乘以标的数量得到相同的名义本金：

```text
名义本金 N = K × q × u = 64,250 × 0.10 × 1 = 6,425 USDT
对应 BTC 数量 = N ÷ K = 0.10 BTC
```

每组对比都以各自的 `N` 作为两边收益率的分母，不加备资缓冲，也不计闲置资金或权利金的利息。

### 双币赢的本期收益

按官方规则，`APR × 天数 ÷ 365` 向下截取到小数点后四位，再乘以申购金额。[Binance 双币赢收益公式](https://www.binance.com/en/dual-investment)

```text
本期收益率 r = floor_to_4dp(2.2355 × 1 ÷ 365) = 0.0061
本期收益     = N × 0.0061 = 6,425 × 0.0061 = 39.1925 USDT
折算单利年化 = 0.0061 × 365 ÷ 1 × 100% = 222.65%
```

所以表内的 **222.65%** 与产品原始报价 **223.55%** 不同，差别来自产品的本期收益率舍入，不是另扣一笔费用。

### 直接卖 Put 的毛权利金

```text
毛权利金 = P × q = 540 × 0.10 = 54.00 USDT
毛年化   = 54.00 ÷ 6,425 × 365 ÷ 1 × 100% ≈ 306.77042802%
毛收益差 = 54.00 − 39.1925 = 14.8075 USDT
相对增幅 = (54.00 ÷ 39.1925 − 1) × 100% ≈ 37.78146329%
毛年化差 = 306.77042802% − 222.65% ≈ 84.12042802 个百分点
```

最高样本图据此展示 **14.81 USDT / 37.78% / 84.12 个百分点**。全部金融运算使用 Decimal，展示时才保留两位小数，差额从未舍入值计算。应用界面的期权年化也使用**未扣费权利金 / 名义本金**；本次仅调整文档展示，没有修改交易计算或资金检查。

以下是该次采样中执行价同为 64,250 USDT 的全部两组配对，均按 **6,425 USDT 名义本金**，卖 Put 数量固定 0.10 张，未行权情景。其他执行价见[逐笔对照表](yield-comparison-samples.md)。

| 到期日，08:00 UTC | 天数 | 双币赢本期收益，USDT | 卖 Put 毛权利金，USDT | 毛收益差，USDT | 毛年化差，百分点 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2026-11-17 | 1 | 39.19 | 54.00 | +14.81 | +84.12 |
| 2026-11-18 | 2 | 67.46 | 83.50 | +16.04 | +45.55 |

同名义本金的毛收益比较公式为：

```text
N = 执行价 × 期权张数 × 每张 BTC 数量
r = floor_to_4dp(双币赢 APR 小数 × 天数 ÷ 365)
双币赢收益 = N × r
卖 Put 毛权利金 = 买一价 × 张数
毛收益差 = 卖 Put 毛权利金 − 双币赢收益
毛年化差（百分点）= 毛收益差 ÷ N × 365 ÷ 天数 × 100
```

README 与图表比较双币赢本期收益和卖 Put 毛权利金，按上述公式计算毛收益差、相对增幅与毛年化差。展示数值保留两位小数，差额使用未舍入值计算。其他执行价的名义本金不同，不能把 66 组都当成 6,425 USDT 的样本。

## 实际费用与备资

毛收益展示不改变交易所收费或应用的资金要求。以下是最高样本的执行成本说明，不纳入宣传图的毛收益计算。

研究当日普通 taker 费率为 **0.024%**，费用以权利金的 **10%** 为上限；不假设 VIP、返佣或其他优惠。费率促销适用于 2025-08-04 起新上市的合约，官方公告于 2026-09-09 更新，检查日期为 2026-11-16。实际费用取决于成交时指数价和适用费率。[费率公告](https://www.binance.com/en/support/announcement/detail/8f1cae716974444da593806e7425e4ff)、[费用公式](https://www.binance.com/en/support/faq/detail/5326e5de61c34fed98abe28d2f175a23)

```text
开仓费 F = min(0.00024 × 指数价 × u, 0.10 × P) × q
         = min(0.00024 × 64,503.71434783 × 1, 0.10 × 540) × 0.10
         = 1.54808914434792 USDT
费后权利金 = 54.00 − F = 52.45191085565208 USDT
```

当前代码对卖 Put 至少按名义本金备资，以 **90% 占用目标**计算权益需求。在无其他仓位、无已有权益的主例中：

```text
准备资金 C = N ÷ 0.90 = 6,425 ÷ 0.90 ≈ 7,138.88888889 USDT
备资缓冲   = C − N ≈ 713.88888889 USDT
```

依据为 [required_margin](../src-tauri/src/strategy/candidates.rs)、[备资占用目标](../src-tauri/src/strategy/margin.rs)及[权益目标计算](../src-tauri/src/app_state/funding.rs)。最终校验的 95% 容差不能用来缩减备资；已有仓位时实际需求也会不同。

若扣开仓费并以完整准备资金 `C` 为分母，主例的资金年化约为 **268.18%**，与宣传图的名义本金毛年化 **306.77%** 是两种口径。

## 行权后为什么不能直接沿用这个差额

双币赢低买触发转换时，将**本金和收益一起**按目标价换成 BTC；本软件的卖 Put 先现金结算，再买入合约对应的 BTC 数量，权利金仍以 USDT 计。即使目标价和到期时间相同，最终收币数量、收益币种和执行时点也不完全一样。[双币赢结算规则](https://www.binance.com/en/support/faq/detail/09911be9f5754c34806bd3ab4a427e0e)、[本软件交割流程](trading-safety.md#下单与交割)

价内到期还涉及期权行权费、现货交易费及实际买入价相对结算价的偏差。官方公布的行权费率为 **0.015%**，并受期权价值 10% 的费用上限约束。[期权费用说明](https://www.binance.com/en/support/faq/detail/5326e5de61c34fed98abe28d2f175a23) 未知未来结算价、成交价及账户适用费用，因此本次不虚构一个“所有情景净省金额”。提前平仓、清算、税费、其他仓位占用或客户端离线造成的执行延迟，也不包含在主图测算中。

年化只用于把不同期限换成同一个比较单位，不代表未来能连续以当前报价复投。实际使用仍按[实盘交易安全](trading-safety.md)要求专号专用、核对订单，并保持客户端处理已登记交割。
