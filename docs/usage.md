# 使用指南

[返回项目首页](../README.md) · [实盘交易安全](trading-safety.md) · [开发指南](development.md)

双币赢助手通过 Binance 期权与现货执行 BTC/USDT 双币赢式策略。新策略由用户手动确认；确认后的恢复、结算和资金收尾可由后台继续执行。

## 连接与界面设置

设置页上方左侧为“Binance 连接”，右侧为“通用设置”，日志位于下方。

API Key 关闭提现权限，仅授予所需的读取、现货与期权交易、Simple Earn 和 Universal Transfer 权限。凭据保存在系统 keyring，不保存在 SQLite 或日志中。Linux 需要可用的 Secret Service / keyring 服务。

启动时会尝试使用 keyring 中已保存的凭据连接。连接成功或点击“同步订单”会读取交易所状态；平时页面刷新读取本地快照，后台定期维护订单并刷新账户展示。账户查询失败时保留上次成功的数据和更新时间，并显示错误提示。

### 界面语言

在“设置 → 通用设置”选择界面语言，支持简体中文、英语、繁体中文、巴西葡萄牙语、西班牙语、越南语、土耳其语、印尼语、日语、韩语和泰语。

- 首次按系统语言优先列表选择支持的语言，均不支持时使用英语。选择“跟随系统”可恢复自动选择。
- 手动选择在词典加载完成后生效并保存在当前设备；存储不可用时仍可在本次会话切换。
- 启动只加载当前语言和英语回退，其他词典在切换时加载并在当前会话缓存。语言资源均随安装包提供，可离线切换。
- 快速切换以最后一次选择为准；加载失败时保留当前语言，启动阶段加载失败时使用英语。
- 切换语言保留当前表单和交易状态；日期仍使用系统本地时区和公历。

## 选择与提交策略

1. 在“双币赢”选择卖 Put 低买或卖 Call 高卖。
2. 按到期日、年化、行权概率或距现价筛选候选，选择合约并输入数量。
3. 查看预计权利金和保本价，在复核窗口确认合约与数量后提交。
4. 在“策略订单”跟踪成交和后续处理，在“总览”查看活跃策略与到期日历。

已连接且进入“双币赢”时没有缓存候选，会自动扫描；已有候选通过“刷新候选”更新。修改数量时的权利金和保本价是本地预估，预览成功不代表已通过实时交易检查；提交后以实际成交回报为准。

候选目标价旁的“持仓”标识表示该合约已有本程序跟踪的活跃策略，包括本机下单和已接管的仓位；仅标记有实际成交的策略，并随订单快照更新。

已有未到期的 BTC/USDT 卖方义务仓可在“策略订单”手动接管。接管登记真实持仓，确认覆盖后续恢复、结算和收尾；具体边界见[实盘交易安全](trading-safety.md#授权与串行)。

## 结算与恢复

期权采用现金结算。保持客户端运行并连接，后台处理价内到期订单的现货补齐和资金归集。未完成批次会预留资金并限制新策略。

异常在“策略订单 → 恢复中心”处理。请求结果待确认时，系统查询原请求；不能将网络错误当作交易失败直接重发。符合条件的失败收尾可选择“结束理财收尾”，未申购资金留在现货。

保证金门槛、备资顺序、资金预留和人工恢复条件见[实盘交易安全](trading-safety.md)。

## 资产与收益口径

页面上的收益预估不代表最终成交或收益承诺。订单与资金事实来自 Binance 或 SQLite 中的真实记录，日志和前端进度不作为事实依据。

### 资产与持仓

- 同名资产合并展示并保留账户来源；合并后无法完整估值的资产保留数量，不计入总资产估值和比例图。
- 义务仓概览只统计运行中或部分成交且有实际成交的订单。卖 Put 的“已成交名义本金”为 `执行价 × 已成交数量`，实际保证金占用以 Binance 账户记录为准。
- 账户展示缓存不参与下单、备资或恢复判断。

### 权利金与累计收益

- 已成交订单的权利金按 `实际成交均价 × 已成交数量` 计算；保本价为卖 Put 的 `执行价 − 成交均价` 或卖 Call 的 `执行价 + 成交均价`。加载本地订单时会从成交字段重算这些派生指标，读取过程不改写数据库。
- 累计收益为订单权利金加上卖 Put 补齐 BTC 的浮动盈亏；后者按 `(现价 − 补齐成交均价) × 补齐成交数量` 计算。不计手续费。
- 收益估值中的现价取最近一次成功账户刷新中的有效 BTC/USDT 价格；未取得有效价格时，浮动盈亏暂显示为 0。
- 日期展示和按日统计使用系统本地时区；“今日权利金”按订单创建日期汇总。到期判断使用合约精确时间。

### 年化预估

年化使用单利估算：

```text
年化（%） = 权利金 ÷（执行价 × 数量基数）× 365 ÷ 到期天数 × 100
```

候选使用预估权利金、候选数量和扫描时点；订单使用成交权利金、已成交数量和记录中的创建时点。到期天数向上取整，至少按 1 天计算。

## 日志与排查

在“设置 → 日志”查看最近记录、打开今日日志或日志目录。文件按本机日期写入应用数据目录下的 `logs/YYYY-MM-DD.log`，每行一条 JSON；消息保存稳定代码与参数，日志面板按当前语言翻译，级别和事件代码保持原值。

日志写入失败只在日志面板反馈，不改变已确认的交易或资金结果。删除日志不影响订单、恢复记录或 keyring 凭据。

反馈问题时附系统环境、复现步骤和脱敏后的错误信息，不附 API 凭据、签名请求或 Binance 原始响应。交易与资金异常先按[恢复规则](trading-safety.md#资金与恢复)核对。
